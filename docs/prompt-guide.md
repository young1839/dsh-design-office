# AI 生成 PPT / PDF / Word / Excel 的最佳提示词指南

> 配套 dsh-design-office 插件使用。核心原则：**把"设计意图 + 信息结构 + 输出约束"讲清楚，AI 才能一次做对**。

---

## 一、总则：一份好提示词的 5 个要素

| 要素 | 说明 | 反面例子 |
|---|---|---|
| **1. 场景/受众** | 给谁看、什么场合 → 决定风格与密度 | "做个 PPT" |
| **2. 核心信息结构** | 页/块级别的骨架（有几页、每页讲什么） | "把这份报告做成 PPT"（没有说重点） |
| **3. 数据与事实** | 表格数字、关键结论原文给出 | "放一些行业数据"（AI 会编） |
| **4. 风格/模板诉求** | 模板 id、配色、渐变、图标主题 | "好看一点"（太模糊） |
| **5. 约束与禁忌** | 页数上限、字体、必须包含/禁止的内容 | 无 |

**提示词模板（通用）**：
```
请生成一份【PPT/PDF/Word/Excel】——《主题》，用于【场景：周会/答辩/路演/简历…】，
受众是【谁】。

内容结构：
1. ……（第 1 页/块：讲什么，含哪些要点/数字）
2. ……
数据（原文，勿编造）：[表格/数字]

风格：用模板【xxx / 科技蓝渐变 / 扁平卡片 / 极简商务 / 办公报告 / 论文报告】，
主色倾向【蓝/绿/橙…】，图标主题【新能源/金融/教育…】。
约束：共 N 页以内；封面标题用《xxx》；封面不要署名/日期（我自己填）；
中文，不用英文占位；数字要真实（不确定就标注"待填"）。
```

## 二、分文档类型的提示词要点

### 1. PPT（design_pptx_create）—— 一页一主题，讲透再翻页
好的提示词给**逐页大纲**而不是一段话：
```
生成一份《2026 新能源行业投资分析》汇报 PPT，受众：投资委员会，风格偏数据严谨。
逐页内容：
P1 封面：主标题+副标题"技术驱动 · 市场变革 · 未来展望"
P2 市场总览（content）：3-4 个要点，含渗透率/增速数字
P3 竞争格局（table）：表头[厂商, 2025销量, 同比]，4-5 行真实数据
P4 季度趋势（chart bar）：两个系列各 4 个季度数值
P5 风险与建议（two-column）：左列风险 2 条，右列建议 2 条
用模板 tech-blue-gradient；每页右上角放 1 个相关图标（颜色 #00A3FF）；
总页数 6 页内。
```
要点：
- **明确每页 type**（title/content/table/chart/two-column/image/section）→ AI 选对版式；
- 表格给**完整表头与行**，避免 AI 编数；
- chart 明确"几个系列、几个类目、bar/line/pie"；
- 图标给出主题词 + 颜色（如"新能源车图标，蓝 #00A3FF"）；
- 需要备注页就写"每页加演讲者备注，控制 30 秒"。

### 2. PDF（design_pdf_create）—— 报告类：先给目录骨架
```
生成《2026 年度经营分析报告》PDF，受众：管理层，A4，需正式、可打印。
结构：
封面标题 + 目录式正文：
一、市场综述（heading2 + 1-2 段）
二、关键数据（heading2 + 表格[指标,2025,2026,增长率]，3-4 行）
三、重点工作（heading2 + 列表 3 项）
四、风险与展望（heading2 + 段落）
配色：封面渐变 深蓝→亮蓝，正文强调色 #0B3B8C，页码开启。
```
要点：PDF 偏"报告"，提示词应给**章节层级**（heading/paragraph/list/table 块），并指定封面渐变/accent/页码。

### 3. Word（design_docx_create）—— 结构化正文 + 样式诉求
```
生成《项目立项申请书》Word，正式文书风。
标题：项目立项申请书
内容块：
heading2 项目背景 → 2 段正文
heading2 预算明细 → 表格[科目,金额(万),备注]，4 行
heading2 预期成果 → 列表 3 项
结尾落款段（空两格：申请人：___ 日期：___）
加浅黄背景 + 斜向"机密"水印；强调色 #92400E。
```
要点：Word 看重**信息完整与格式**——背景色/水印/accent 直说；需要封面插图给 `cover_image` 路径；水印文字与背景色可同用（修复后互不冲突）。

### 4. Excel（design_xlsx_write）—— 先给"表结构"（列名+样例行）
```
生成《季度销售数据表》Excel：
表头：产品 | Q1 | Q2 | Q3 | Q4 | 合计
数据 4 行（产品A/B/C/D 各季度数值，合计用公式 SUM）
sheet 名"销售数据"；表头深蓝白字加粗；数值列加色阶；列宽 [12,8,8,8,8,10]。
```
要点：Excel 给**列名 + 行数据**即可，样式项（表头色/色阶/列宽）可选；数值列不要给公式就写死数字，说明"合计列用公式"让工具支持。

## 三、让 AI"少返工"的 6 个实操技巧

1. **先说数据，再说排版**：数据给全（表格原样），AI 只做布局设计，避免"编数"。
2. **风格指定到"模板 id/色值"级别**：`用模板 flat-cards`、`主色 #4F46E5`，比"高大上"有效得多。
3. **页/块数量与内容双重限定**：既说页数又说每页内容 → AI 不会自己加页或漏内容。
4. **封面与落款占位**：封面日期/署名这类"你后填"的内容让 AI 留空或占位，避免生成错日期。
5. **一次给齐素材**：图标主题词、封面图路径、用户模板路径随提示词一起给，AI 不会二次追问。
6. **生成后自查闭环**：让 AI"用 doc_read_* 读回并对照提示词核对页数/表格/无占位符（lorem/TODO）"，AI 会自检一遍。

## 四、提示词反面教材 vs 改进版

❌ "帮我做个产品介绍的 PPT，好看点。"
✅ "做《智能客服产品介绍》PPT（10 页内，受众：潜在客户，模板 flat-cards）。
P1 封面：产品名 + slogan；P2 痛点（4 要点）；P3 产品架构图（image，用我给的架构图
   workspace/arch.png）；P4 功能清单 table[功能,说明] 6 行；P5 客户案例（2 栏 3 个）；
   P6 定价（table 3 档）；P7 联系我们。
图标用 客服/机器人/数据 主题，颜色 #4F46E5；结尾页不写电话（占位）。
"

❌ "写个季度总结 Excel。"
✅ "季度销售总结表：表头[区域, 销售额, 同比, 目标完成率]；华东/华南/华北/西南 4 行，
   数字 [120万/+15%/96%, …]；表头深蓝白字；完成率列色阶；sheet'Q3 总结'。"

## 五、一句话速查（给 AI 的固定话术后缀）

> "请：1) 用真实/我提供的数据，不编造；2) 中文字体优先；3) 生成后 doc_read 自查，
> 报告文件路径与页/块数；4) 有图标/素材引用走 asset_* 工具；5) 成品放 workspace/ 下。"

按此写提示词，配合 dsh-design-office 的模板/识图门禁，基本一次成型、只需微调。
